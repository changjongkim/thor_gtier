# 폐기 — 고장난 승인 경로로 측정한 결과

이 디렉터리의 실행은 `full_admit`의 축출 후보 선정이 **디코드 가중치를 쓰지 않고,
사용 중인 유닛을 제외하지도 않은** 상태에서 측정됐다. 세 번의 패치가 존재하지 않는
텍스트에 매칭돼 조용히 적용되지 않았고, 단언은 파일 다른 곳의 같은 문자열에 걸려
통과했다(커밋 7d909c2).

증상: 예산 24 steady에서 토큰당 I/O가 34.30 ms에 고정되어 어떤 정책 변경에도 움직이지
않았다. 고친 뒤 같은 설정이 8.71 ms다.

베이스라인(`lru`, `moe-inf*`, `mixtral*`)과 어블레이션(`per-layer`, `prefix`)은 이 결함의
영향을 받지 않지만, 같은 바이너리에서 다시 측정한 값으로 대체한다.
